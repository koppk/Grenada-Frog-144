# Reference genome selection via phylogenetic proximity

Complementary to the k-mer-based distance estimation (Mash), this
section identifies the closest chromosome-level reference genome for
scaffolding by ranking anuran species by divergence time to
*Pristimantis euphronides* using the Portik et al. (2023)
time-calibrated phylogeny.

Corresponds to Additional file 2, section **"Reference genome selection
via phylogenetic proximity"** and Additional file 3 (Supplementary
Results), same section.

All scripts, input data, and output files are in
`Divergence_times_and_biogeographic_context/`.
