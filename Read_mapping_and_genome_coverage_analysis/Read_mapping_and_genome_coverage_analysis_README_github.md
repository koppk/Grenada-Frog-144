# Read mapping and genome coverage analysis

Scripts for the read mapping and genome coverage analysis
of the *Pristimantis euphronides* genome assembly.

Corresponds to Additional file 2, section **"Read mapping and genome coverage
analysis"** and Additional file 3 (Supplementary Results), section
**"Read mapping and genome coverage analysis"**.

Input and output data files are deposited at Zenodo (doi: [10.5281/zenodo.15298547](https://doi.org/10.5281/zenodo.15298547)).

## Scripts

Scripts are numbered in execution order. Each script reads from hardcoded
input paths and writes to a single `output/` directory.

| Script | Description | AF2 Step |
|--------|-------------|----------|
| `01_map_reads_and_compute_coverage.sh` | Align HAC reads with Minimap2; compute 10 kb windowed coverage with mosdepth | 1, 2a |
| `02_compute_coverage_summary_statistics.py` | Summary statistics at genome-wide and scaffold 1–13 scopes; per-scaffold breakdown | 2b–2d, 3 |
| `03_plot_genome_coverage.py` | Genome-wide smoothed coverage plot across scaffolds 1–13 (Figure SR5) | 4, 5 |
| `04_plot_individual_scaffolds.py` | Individual per-scaffold coverage plots (Additional file 9, panels A–M) | 4 |
| `05_detect_coverage_anomalies.py` | Detect low- and high-coverage anomalies from 10 Mb smoothed profile | 6 |

### Prerequisites

- minimap2 v2.28 ([Li, 2018](https://doi.org/10.1093/bioinformatics/bty191))
- samtools v1.19.2 ([Danecek et al., 2021](https://doi.org/10.1093/gigascience/giab008))
- mosdepth v0.3.11 ([Pedersen & Quinlan, 2018](https://doi.org/10.1093/bioinformatics/btx699))
- Python 3.11+ with: pandas, numpy, scipy, matplotlib

### Execution

```bash
cd /data/GrenadaFrog144/coverage

# Step 1 + 2a (alignment and mosdepth — already completed; rerun only if needed)
bash scripts/01_map_reads_and_compute_coverage.sh

# Step 2b–2d, 3 (summary statistics)
python3 scripts/02_compute_coverage_summary_statistics.py

# Step 4–5 (genome-wide plot — Figure SR5)
python3 scripts/03_plot_genome_coverage.py

# Step 4 (individual scaffold plots — Additional file 9)
python3 scripts/04_plot_individual_scaffolds.py

# Step 6 (anomaly detection)
python3 scripts/05_detect_coverage_anomalies.py
```

## Input and output files

Input and output data files are available from the Zenodo archive
(doi: [10.5281/zenodo.15298547](https://doi.org/10.5281/zenodo.15298547)).
The BAM file (`eup_reads.bam`, ~55 GB) is too large for Zenodo; raw
sequencing reads are deposited at the European Nucleotide Archive (ENA)
and the BAM can be regenerated using script 01.

### Input files

| File | Generated by | Description |
|------|-------------|-------------|
| `eup_reads.bam` | Script 01 | Minimap2 v2.28 alignment of HAC ONT reads to the RagTag-scaffolded *P. euphronides* assembly |
| `eup_cov.regions.bed` | Script 01 | mosdepth v0.3.11 (`--by 10000`), non-overlapping 10 kb windows; 190,258 windows; ~28 MB |
| `eup_cov.mosdepth.summary.txt` | Script 01 | mosdepth per-scaffold and total coverage summary; ~1.5 MB |
| `ragtag.scaffold.renamed.agp` | RagTag v2.1.0 | AGP file defining scaffold structure; scaffold names renamed from *E. coqui* accessions to scaffold_1 through scaffold_31; ~1.6 MB |

### Output files

| File | Generated by | Description |
|------|-------------|-------------|
| `coverage_summary_statistics.tsv` | Script 02 | Summary statistics at two scopes (genome-wide, scaffolds 1–13) and per-scaffold breakdown |
| `genomewide_scaffolds1_13_with_trend_and_mean.png` | Script 03 | Genome-wide coverage plot (Figure SR5); 300 dpi |
| `scaffold_1.png` … `scaffold_13.png` | Script 04 | Individual scaffold plots (Additional file 9, panels A–M); 300 dpi |
| `coverage_anomalies_smoothed.tsv` | Script 05 | Low- and high-coverage anomalies (smoothed profile, ≥300 kb) |
